# Estatein - сайт агентства недвижимости

Estatein - учебный сайт агентства недвижимости, разработанный в рамках курса по веб-программированию. В качестве основы мы выбрали готовый дизайн-макет **Real Estate Business Website UI Template - Dark Theme** из Figma и сверстали по нему страницу с каталогом объектов, отзывами клиентов и ответами на частые вопросы.

## Что реализовано

- **HTML:** структура страницы, меню навигации, первый экран, преимущества сервиса, карточки недвижимости, отзывы, FAQ и подвал сайта.
- **CSS:** тёмная цветовая схема, шрифт Urbanist, сетки карточек, кнопки, отступы и оформление по макету Figma. Для изображений и иконок использованы локальные файлы из `assets/`.
- **JavaScript:** интерактивные элементы страницы без перезагрузки.

### Функции JavaScript

1. **Закрытие баннера:** кнопка-крестик скрывает верхнее уведомление.
2. **Переключение карточек:** стрелки меняют порядок карточек в разделах недвижимости, отзывов и FAQ; счётчик показывает текущую позицию.
3. **Просмотр недвижимости:** кнопка **View Property Details** открывает модальное окно с фотографией, названием, характеристиками и ценой выбранного объекта. Окно можно закрыть кнопкой или нажатием вне него.
4. **Раскрытие FAQ:** кнопка **Read More / Read Less** показывает и скрывает ответ на вопрос.
5. **Email-форма:** браузер проверяет формат адреса; после отправки появляется информационное сообщение. Форма демонстрационная - данные никуда не отправляются и не сохраняются.

## Технологии

HTML5, CSS3 и JavaScript без фреймворков. Для вёрстки использованы Flexbox и CSS Grid.

## Как запустить

Откройте `index.html` в браузере или запустите проект через **Live Server** в Visual Studio Code. Все основные изображения находятся в папке `assets/`. Для загрузки шрифта Urbanist нужен доступ к Google Fonts.
